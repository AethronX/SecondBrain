# NAZZIM brand palette

Taken from the live site, not invented. Purple/violet on light lavender.

| Token | Hex | Use |
|---|---|---|
| ink | `#0B0B14` | headline line 1, wordmark |
| muted | `#9A9AAE` | eyebrow |
| soft | `#6B6B80` | sub-copy |
| faint | `#A8A8BC` | meta, right column |
| paper | `#F7F6FD` | sheet background |
| brand-1 | `#4F52E8` | gradient start |
| brand-2 | `#9B51E0` | gradient end |
| screen | `#0E0E18` | Notion cover base |

Headline follows the site: **line 1 in ink, line 2 in the purple gradient.**

Inside the Notion UI the functional colours stay as they are — green for
completed, red for overdue, the zone colours on navigation. Those are Notion's
own semantics and the product's, not the brand's, and overriding them with
purple would cost meaning to gain nothing.
